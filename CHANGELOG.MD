v1.8 – 14 October 2026

Automatic updates

The app checks GitHub for a newer release when it starts and shows a small notification with Install and Ignore buttons.
Install downloads SnickerTweakerOptimizer.exe from the release, verifies its SHA-256 checksum, replaces the old file and restarts the app. If the check fails, nothing is installed.
Ignore hides the notification for that version.
New Settings > Updates section: "Check now" button and a switch to turn the startup check on or off.
Works with the .exe only. With Launch-SnickerTweaker.bat the app just opens the release page.

v1.7 – 14 October 2026

First release on GitHub.

Dashboard: automatic PC scan (CPU, GPU, RAM, storage, board/BIOS, OS, display, network), hardware profile, live CPU/RAM/GPU readout and an "optimized" score.
Tweaks: FPS and latency, hardware-specific, registry, and debloat/privacy tweaks. Only the ones that suit your PC are shown. Every tweak saves the original value and can be undone.
Games page: 29 popular games with search and filters, presets (Balanced, Competitive, Max FPS), Auto Game Mode, and Counter-Strike 2 config and presets.
Benchmark page: before/after tests (CPU, memory, timer, disk, network, idle load) with a saved report.
Settings page: restore status, language (English / Dansk), dark and light theme, undo everything, restore point, diagnostics, and advanced options.
Also included: Gaming Check, BIOS guide, Network tools (ping and DNS benchmark), Repairs, Drivers page, Startup manager, Boost-Up cleaners, and one-click installs of gaming runtimes.
